# فروشگاه دیبا — قالب فروشگاه اینترنتی

قالب کامل یک فروشگاه اینترنتی فارسی (راست‌به‌چپ)، همراه با پنل مدیریت، ساخته‌شده با React.
نام «دیبا» و تمام محصولات فقط محتوای نمونه هستند و برای سفارشی‌سازی راحت انتخاب شده‌اند — هر بخش از پروژه قابل تغییر است.

## اجرای پروژه

```
npm install
npm run dev
```

سپس آدرسی که در ترمینال نمایش داده می‌شود (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

برای گرفتن خروجی نهایی جهت آپلود روی هاست:

```
npm run build
```

فایل‌های نهایی داخل پوشه `dist` ساخته می‌شوند.

## ورود به پنل مدیریت

- آدرس: `/admin`
- رمز عبور نمونه: `admin1234`

پنل شامل داشبورد، مدیریت محصولات (افزودن/ویرایش/حذف/موجودی)، دسته‌بندی‌ها و سفارش‌هاست.

## این نسخه چه چیزی هست، و چه چیزی نیست

طبق انتخابی که در ابتدای کار شد، این نسخه با **داده نمایشی (demo data)** کار می‌کند، نه یک بک‌اند واقعی:

- تغییرات در پنل مدیریت همان لحظه در سایت دیده می‌شود، ولی با رفرش صفحه به حالت اول برمی‌گردد.
- ثبت سفارش در فروشگاه واقعاً پرداختی انجام نمی‌دهد — فقط سفارش را (در همان حافظه موقت) ثبت می‌کند تا مسیر کامل خرید قابل بررسی باشد.
- ورود به پنل مدیریت هم یک رمز نمایشی ساده است، نه یک سیستم احراز هویت واقعی.

هر سه مورد از قبل طراحی شده‌اند که جایگزین‌کردنشان راحت باشد — به بخش «مرحله بعد» در پایین همین فایل مراجعه کنید.

## ساختار پروژه

```
src/
  data/         داده‌های نمونه (محصولات، دسته‌بندی‌ها، سفارش‌ها) — اولین جا برای تغییر محتوا
  services/     dataService.js — تنها فایلی که باید برای اتصال به بک‌اند واقعی عوض شود
  context/      وضعیت سبد خرید و داده‌های فروشگاه (React Context)
  components/   قطعات قابل‌استفاده‌مجدد UI (دکمه، مودال، کارت محصول، هدر و...)
  pages/        صفحات اصلی فروشگاه (خانه، فروشگاه، محصول، سبد، تسویه‌حساب)
  admin/        پنل مدیریت (چیدمان، صفحات، فرم‌ها)
  styles/       تمام فایل‌های CSS — همیشه از variables.css شروع کنید
```

## سفارشی‌سازی سریع

- **رنگ، فونت، فاصله‌ها:** همه در `src/styles/variables.css` به‌صورت متغیر تعریف شده‌اند. تغییر مقدار در همان‌جا، کل سایت (فروشگاه + پنل مدیریت) را یکجا به‌روزرسانی می‌کند.
- **نام فروشگاه:** رشته «دیبا» را در `Header.jsx`، `Footer.jsx` و `AdminLayout.jsx` جایگزین کنید، و عنوان صفحه را در `index.html`.
- **محصولات و دسته‌بندی‌ها:** فایل‌های `src/data/products.js` و `src/data/categories.js` را مستقیم ویرایش کنید، یا از پنل مدیریت استفاده کنید.
- **عکس واقعی محصول:** الان به‌جای عکس واقعی یک پترن رنگی نمایش داده می‌شود (`ProductImage.jsx`) — فقط کافیست مقدار `image` را به هر محصول اضافه کنید، عکس واقعی به‌طور خودکار جای پترن را می‌گیرد.

## مرحله بعد (هر زمان که نیاز شد)

- **بک‌اند واقعی:** فقط `src/services/dataService.js` نیاز به تغییر دارد — توابع داخلش باید به‌جای آرایه‌های حافظه، به یک API واقعی وصل شوند؛ بقیهٔ پروژه بدون تغییر ساختاری کار می‌کند.
- **درگاه پرداخت:** داخل `src/pages/Checkout.jsx`، محل دقیق اتصال درگاه (مثل زرین‌پال یا آی‌دی‌پی) با یک کامنت مشخص شده است.
- **حساب کاربری مشتری:** در این نسخه ساخته نشده (چون بدون بک‌اند واقعی معنای چندانی نداشت)، اما ساختار پروژه برای افزودنش آماده است.

از هیچ سرویس غیرفعال در ایران (مثل Firebase) استفاده نشده؛ فونت هم به‌صورت کامل داخل پروژه (npm) بسته‌بندی شده، نه از یک سرویس خارجی.

## آپلود روی GitHub Pages

این پروژه از قبل برای GitHub Pages آماده شده (مسیر `base` در `vite.config.js` و
روش مسیریابی در `main.jsx`). قدم‌ها:

1. یک بار مقدار `base` در `vite.config.js` را با نام دقیق ریپازیتوری خودتان
   جایگزین کنید: `base: '/نام-ریپازیتوری-شما/'`.
2. کدها را در یک ریپازیتوری روی GitHub پوش کنید (مثل هر پروژه دیگر).
3. یک‌بار پکیج‌ها را نصب کنید (اگر قبلاً نکرده‌اید): `npm install`
4. برای هر بار آپلود نسخه جدید: `npm run deploy`
   (این دستور اول `npm run build` را اجرا می‌کند، بعد نتیجه را در برنچ `gh-pages`
   می‌گذارد.)
5. در تنظیمات ریپازیتوری، بخش Pages → Source را روی برنچ `gh-pages` بگذارید.
6. سایت روی `https://username.github.io/نام-ریپازیتوری-شما/` بالا می‌آید.

نکته: این پروژه از `HashRouter` استفاده می‌کند (آدرس‌ها با `#/` مثل
`.../#/shop`) نه `BrowserRouter`. دلیلش این است که GitHub Pages یک هاست کاملاً
استاتیک است و نمی‌تواند مسیرهای داخلی React Router (مثل رفرش کردن مستقیم صفحه‌ی
`/shop`) را به‌درستی به `index.html` هدایت کند؛ `HashRouter` این مشکل را کامل
دور می‌زند. اگر بعداً به هاستی رفتید که این محدودیت را ندارد، می‌توانید در
`main.jsx` به `BrowserRouter` برگردید تا آدرس‌ها بدون `#` باشند.

## فناوری‌های استفاده‌شده

React 18 + React Router + [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (فونت فارسی) + [lucide-react](https://lucide.dev) (آیکون). بدون کتابخانه اضافه برای مدیریت وضعیت یا استایل — CSS خام و Context خود React.
